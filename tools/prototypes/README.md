# tools/prototypes — 2026-11-11 に書いた試作スクリプト（記録）

このフォルダは記録です。2026-11-11 に、`fd` にまだ機能がなかった作業を、その場で書いたスクリプトで行いました。ペンの描画と、箱からのキャップの取り出しは、いまは `fd` のコマンドに置き換わっています。**ここのスクリプトは、いまの構成では動きません。** ハーネスのモジュールも、このフォルダを import しません。

| フォルダ | 中身 | いまのコマンド |
|---|---|---|
| `pen_draw/` | 2026-11-11 の夜に、グリッパーにテープで留めたペンで猫の線画を 1 枚描いたときのスクリプト（ペン先の校正、位置補正、描画、追従の測定）と、そのときの設定と状態のファイル | `fd tool …`、`fd draw`、`fd track-test`、`fd snap --exposure paper`。スクリプトごとの対応表は [`pen_draw/README.md`](pen_draw/README.md) にあります |
| `stacking_20261111/` | 同じ日の、積み上げ、皿への仕分け、キャップの壁をつまむ取り出しのスクリプト。`fd` の低レベルコマンド（`tip`、`grip`、`grasp`、`snap` など）を順に呼ぶ | 取り出しは `fd take`。積み上げと皿への仕分けには、まだ専用のコマンドがありません（[docs/MANUAL.md](../../docs/MANUAL.md) 9 章） |

## 動かない理由

- `pen_draw/penlib.py` は、`pen_draw/` の 2 つ上のフォルダに、ハーネスのモジュール（`robot`、`camera`、`kinematics`）と、`fd`、`config.json` が並んでいる前提で書かれています。いまの構成では、そこは `tools/` です。モジュールは機能フォルダの中にあるので、import で止まります。
- `stacking_20261111/` のスクリプトは、開発機の当時のフォルダを、絶対パスで指しています。
- MANUAL の 5 章と 9 章に、`stacking_20261111/hover_check.py` の名前が出てきます。このスクリプトも動かないので、5 章にあるもう 1 つの方法（`fd snap --crop x0,y0,x1,y1 --scale 4 --plain` で 1 枚撮って見比べる）を使ってください。

## 実機での状況

実機で動いた実績があるのは、この試作の方です。`pen_draw/` は、2026-11-11 の夜に猫を 1 枚描きました（線 18 本、234.6 秒。猫と分かりますが、線は途切れました）。`stacking_20261111/` では、5 個の仕分けと 4 段の塔を行いました。置き換えた `fd take`、`fd tool …`、`fd draw` は、シミュレーションと保存した写真でしか確かめていません（[PROGRESS.md](../../PROGRESS.md)）。試作と `fd` のコマンドを混ぜて使わないでください。このフォルダにテストはありません。
