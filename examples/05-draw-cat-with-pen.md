# 05 ペンで猫の絵を描く

グリッパーにテープで留めたペンで、紙に線画を描きます。**下のコマンドは、実機ではまだ一度も動かしていません**（確かめたのは、シミュレーションと 2026-11-11 の保存写真だけ）。

## プロンプト

> SO-101の先にマジックペンをつけました。猫の絵を描いてください

## AI がすること

ペンのキャップを外し、紙をテープで留めてもらってから、この順に 1 コマンドずつ実行します（CLAUDE.md「ペンで描く」）。最初に必ず登録します。登録がないまま `fd park` を実行すると、ペン先を机に押し込むためです。校正と描画には数分かかります（シミュレーションで約 5〜6 分と約 4〜5 分）。Bash の timeout を 600000 ms にして、フォアグラウンドで 1 回だけ呼びます。うまく行かなくても、AI は自分で手順を組みません。

```bash
./fd tool attach --name pen --along-fingers 0.055   # 登録。指先からペン先までの長さ（m）を定規で測る
./fd tool calibrate --dry                           # 写真 1 枚と計画だけ。何も動かない
./fd tool calibrate                                 # 紙の上で測る: 先端 → 接触高さ → 位置補正 → 線の向き
./fd draw cat --dry                                 # 配置とプレビュー画像。何も動かない
./fd draw cat                                       # 描く → 最後に写真で線を確認
./fd tool rest                                      # 片付け（ペンが付いている間、park は使えない）
./fd tool detach                                    # ペンを手で外したと人が言ってから（付いたままだと、次の park がペンを机に押し込む）
```

## 返ってくるもの

どのコマンドも JSON 1 個です: `ok` / `stage` / `reason` / `next` / `say` / `pen`（ペン先の高さとアームの状態）/ `photos`。`fd draw` の `ok` は、最後の写真で線の 85 % 以上が確認できたかで決まります（欠けた所は `coverage.gaps`）。

## AI が人に伝えること

`say` をそのまま伝えます。`fd draw` が成功したときの `say` は、「「…」を描きました（… 本、線の … % が写真で確認でき、ずれは平均 … mm）。」の形です。

## 状況

- 実機で描いた猫は 1 枚だけです。2026-11-11 の夜に、その場で作った試作スクリプト（`tools/prototypes/pen_draw/`）で描きました。線 18 本、234.6 秒。猫と分かりますが、線は途切れました（PROGRESS.md）。動画: [[Tazuna開発記] マジックペンで絵を描いてみる](https://www.youtube.com/watch?v=Fakua6h1_IE&list=PLS2xQbZhQGBk)
- `fd tool …` と `fd draw` は、そのとき分かったことを `fd` のコマンドとして作り直したものです。シミュレーションでは猫 18 本・約 225 秒で、線の 99.9 % を確認できました。これは実機の成績ではありません（docs/MANUAL.md 4 章）。
- 記録にあるのは 2 つです。2026-11-12 朝の登録（`fd tool attach … --no-robot`。アームは読まず、登録を書いただけです）と、シミュレーションの `./fd --sim draw cat --dry`（`ok: false`、`stage: "tool"`、`say`:「ツール「pen」は未校正です（contact, map）。先に fd tool calibrate を実行してください。」）です。

## うまくいかないとき

- **`stage: "visual"`**（写真で線の有無を判定できない）: 深くしません。`./fd snap --exposure paper` で 1 枚見て、照明や紙の上の物を直し、同じ段階をやり直します。
- **`interrupted: true`**（打ち切り・中断）: 同じコマンドをすぐ繰り返しません。`./fd tool rest` のあと、写真を 1 枚見て人に伝えます。
