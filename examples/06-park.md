# 06 作業を終えて、アームを収納する

## プロンプト

> 終わりです。アームを収納してください

（言い方の例です。`park` を頼んだ人の言葉は、記録に残っていません。）

## AI がすること

収納姿勢に戻してトルクを切り、カメラを自動露出に戻します（CLAUDE.md「依頼を受けたら」の 4）。続けて作業するなら、park しません。待機姿勢のままの方が、次の依頼が速いためです。`fd torque off` は腕が落ちるので、代わりには使いません。

```bash
./fd park
```

## 返ってくるもの

- `ok: true` と `parked: true` のあとに、アームの状態（関節角 `q_deg`、手先位置 `tip_xyz`、温度、電圧など）が続きます。`say` はありません。
- 実機の記録: 2026-11-11 11:01:41 に `ok: true`、4.57 秒（[01](01-put-one-in-box.md) の `fd do` のあと）。同じ日の 10:13:17 は 6.56 秒でした。
- すでにトルクが切れていて収納姿勢のときは、何も動かさず、`note` に `torque was already off; nothing moved` と入ります。

## AI が人に伝えること

`parked: true` を見て、収納してトルクを切ったことを自分の言葉で伝えます。

## 状況

**実機で実行済み**です（上の記録）。

## うまくいかないとき

- **ペンなどの道具が付いている**: `fd park` は断られます。片付けは `./fd tool rest` です。シミュレーションの記録（2026-11-12 09:29:09、`./fd --sim park`）では `ok: false`、`stage: "tool"` で、`say` は「グリッパーにツール「pen」が付いているので、park は実行しませんでした（アームは動かしていません）。片付けるときは fd tool rest、ツールを外したあとは fd tool detach を使ってください。」でした。
- **収納する場所に物がある**: `fd park` は、机の上の物を見ずに腕を下ろします。ロボットの正面（爪先が x 約 0.18、y 約 0.01 のあたり）に物があるときは、先にどけてもらいます。
